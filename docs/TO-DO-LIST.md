## 항목 상세

### 2. 국면 자동 재생 버튼

- **내용**: 기본→공격→수비를 일정 간격으로 자동 순환 재생(모핑 애니메이션 시연용). 재생 중 국면 탭 비활성화. 시연·발표·SNS용.
- **기술 메모**: `PHASE_TRANSITION_MS`(600ms) 기존 상수 재사용, 인터벌 1.5~2초 정도. 작업량 반나절.

### 3. 감독 프리셋 추가

- **내용**: 후보 — 무리뉴, 안첼로티, 투헬, 포체티노 등 + K리그 감독. `frontend/public/samples/managers/`에 JSON 추가 + `ManagerPresetPicker` 배열 등록이 전부.
- **유의**: 좌표는 공개 전술 분석 기반 재구성(실제 트래킹 아님) — 기존 프리셋과 같은 주석 유지. 감독 최신 이력(해임·이적)은 추가 시점에 다시 확인한다.

### 4. 상대팀 프리셋

- **내용**: 오버로드 레이어는 `opponentPositions`가 있어야 동작하는데 지금은 11개 점을 일일이 찍어야 함. 감독 프리셋에 상대팀 기본 대형을 옵션으로 포함하거나, 상대 포메이션만 따로 고르는 UI.
- **기술 메모**: 스키마 변경 불필요(`opponentPositions` 이미 optional로 존재). 미러링 로직(`addOpponents`의 y'=100-y) 재사용.

### 5. 타임라인 (매치 체인징 포인트)

- **내용**: 3국면 고정을 넘어 경기 시간 축에 체인징 포인트를 여러 개 찍고 시점별 대형 저장. "전반 23분 추격 상황" 재현.
- **기술 메모**: 프론트 스토어·zod가 이미 대비함 — `convertKeys`가 `phases` 맵 키를 보호하는 이유가 이 확장이다(`api.ts` 주석 참조). 국면 키가 `base/attack/defense`에서 벗어나도 깨지지 않음. DB `phases.phase_type`은 문자열이라 호환. UI(타임라인 바)가 주 공수.

### 6. GIF/영상 내보내기

- **내용**: 국면 전환 모핑 애니메이션 자체를 SNS용 GIF/MP4로. PNG 다음 자연스러운 확장.
- **기술 메모**: 프레임 캡처(html-to-image 반복)→인코딩은 무거움. gif.js(Web Worker) 또는 MediaRecorder(canvas 스트림) 중 택일. 조사 필요.

### 7. 분석 목록 고도화

- **내용**: 목록 화면에 썸네일 미리보기(base 국면 미니 렌더링), 제목·날짜 검색, 태그. 목록이 수십 개가 되면 필요.
- **기술 메모**: 썸네일은 저장 시점에 base 국면을 작은 PNG로 만들어 두는 방식(목록 조회 시 렌더링은 느림) — 백엔드에 파일 또는 BLOB 컬럼 필요.

### 8. 공유 링크

- **내용**: 저장된 분석의 읽기 전용 URL. 로그인 없이 열람만.
- **기술 메모**: 공개 배포 + 공개 조회 API 필요. 데이터가 공개된다는 점 사용자 동의 필요.

### 9. 실제 경기 명장면 프리셋 (StatsBomb OpenData)

- **내용**: 원래 원했던 "실제 경기 분석"의 부분 실현. StatsBomb OpenData(무료, GitHub 공개)의 이벤트 데이터에는 슈팅 순간 양 팀 전원의 실제 좌표(freeze frame)가 담겨 있어, 이를 국면 프리셋으로 변환하면 "2022 월드컵 결승 결승골 장면" 같은 실제 배치를 불러올 수 있음.
- **제약 (중요)**: 슈팅 장면 위주(전 경기 트래킹 아님), 좌표계 변환(StatsBomb는 0~120 × 0~80) 필요, 원본 JSON이 커서 사전 가공 스크립트 필요. 작업량 중~대.
- **연혁**: "실제 경기를 DB에서 검색해 자동 분석"은 2026-09-01 무료 API가 국면별 선수 좌표를 제공하지 않아 기각 → 감독 프리셋으로 대체. 이 항목은 그 대안의 확장.

### 10. 배포 (Docker)

- **내용**: 저장소 루트의 `Dockerfile`/`docker-compose.yml`(백엔드 이미지 + `./data` 볼륨 마운트)은 이미 존재. 남은 결정: 프론트 빌드 산출물을 백엔드 이미지에 정적 서빙으로 포함할지 별도로 둘지.
- **기술 메모**: 컨테이너에서 `npm run build` → FastAPI가 `dist/`를 StaticFiles로 서빙하는 단일 이미지 구성이 가장 단순. 개발은 계속 로컬 2프로세스.

### 11. 로그인/계정

- **내용**: 분석 목록을 사용자별로 분리. 로컬 1인용인 동안은 의미가 제한적이라 배포 이후로 미룸.

### 12. 커뮤니티/댓글

- **내용**: 공유된 분석에 의견. 로그인·배포 이후의 마지막 단계.

### 14. 교체 선수(벤치) 포함

- **상태**: 2026-09-01 사용자 제안
- **내용**: 스쿼드를 11명 고정에서 선발 11 + 벤치(최대 12)로 확장. 벤치는 명단·PNG 카드에 표시되고 피치에는 나오지 않음.
- **기술 메모**:
  - zod `players`를 `.length(11)` → `.min(11).max(23)`으로 완화. `positions`는 계속 정확히 11개(선발만)
  - **선발 여부 컬럼 불필요** — positions에 등장하는 player가 선발, 미등장이 벤치. DB는 players 행만 추가되고 positions 행이 없으므로 **마이그레이션 없음**
  - superRefine에 "positions 11개의 playerId는 서로 중복되지 않아야 함" 검증 추가
  - UI: 선수 목록에 '선수 추가' 버튼 + 선발/벤치 구분 표시

### 16. 전술 대결(매치업) 뷰 — 저장된 전술 2개 대전

- **상태**: 2026-09-01 사용자 제안 ("내가 만든 전술 2개를 서로 경기 시켜보는 것")
- **내용**: 저장된 분석 2개를 골라 한 피치에 오버레이. 내 전술 A의 **공격 국면** vs 상대 전술 B의 **수비 국면**을 겹쳐 보여주고, 자동으로 교대(B 공격 × A 수비 ↔ A 공격 × B 수비)하며 모핑 재생. "내 4-3-3 공격이 상대 4-4-2 로우블록을 어떻게 깨는지" 검증용.
- **기술 메모**:
  - 좌표 규약이 이미 통일(자팀 골 = y=100)이라 **양 팀을 한 피치에 그대로 겹칠 수 있음** — 미러 변환 불필요. A는 자팀 색, B는 상대팀 색으로 렌더링
  - 11+11=22명이므로 오버로드 레이어가 바로 의미 있어짐
  - 새 라우트(`/versus`) + 분석 2개 선택 UI. 백엔드 조회 API만 재사용(수정 없음). 항목 2(자동 재생) 로직 공유
  - **범위 밖**: 실제 스코어·볼 시뮬레이션 — 확률 기반 가짜 점수는 "경기 시켜보기"의 기대를 배신하기 쉬워 포함하지 않음. 원하면 3차에서 가벼운 버전(예: 압박라인·오버로드 기반 우위 하이라이트) 별도 검토

### 18. 감독 프리셋 선수 실명·실제 등번호 교체 — 2026-09-01 사용자 요청

- **상태**: **2026-09-01 구현 완료** — 사용자 확인 대기
- **내용**: 7종 프리셋의 자리표시자 선수명(`GK`,`CB`,`DM` 등)을 해당 시즌 실제 주전과 등번호로 교체. 코멘트 속 등번호 언급도 전부 실제 번호로 재작성.
- **대상 시즌**: 맨시티 23/24, 아스널 23/24, 리버풀 21/22, PSG 23/24, 레버쿠젠 23/24(무패 우승), 광주FC 2023, 수원삼성 2026(K리그2, 이정효 부임 첫 해)
- **조사 방법**: 웹 검색 기반 스쿼드·등번호 교차 확인(위키백과 시즌 문서, 구단 공식, 90min 등번호 발표 기사, K리그는 나무위키·기사 교차). 등번호가 로테이션으로 여러 명 걸쳐 있는 자리는 대표 1인을 선택하고 summary에 로테이션 사실을 짧게 덧붙임(예: 시티 더블피벗 파트너, 아스날 하버츠 CM→ST 전환, PSG 왼쪽 풀백 멘드스/에르난데스, 레버쿠젠 3백 로테이션)
- **중요 정정**: 원래 "수원삼성 2025시즌·K리그1·이정효 4-3-3" 가정은 사실과 다름 — 실제 이정효 감독의 수원 부임은 **2026시즌·K리그2**이고 전술은 **4-4-2**. 프리셋을 formation `4-3-3`→`4-4-2`로 다시 짜고, 좌표·화살표·코멘트를 전부 새로 작성했다. 사용자가 원래 제시한 예시("고승범이 내려와 3백을 만든다")는 4-4-2 안에서 중앙 미드필더 2명 중 더 깊은 고승범이 내려오는 서사로 그대로 유지
- **검증**: `players` 11명·등번호 중복 없음·코멘트에 언급된 등번호가 실제 스쿼드에 존재하는지 자동 검사하는 스크립트로 7종 전부 통과. vitest 39개·빌드·E2E(수원 4-4-2 라벨, 광주·아스날 실명 로딩) 확인 완료
