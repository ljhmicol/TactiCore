- [C] **6. GIF 내보내기** (2026-09-08 사용자 확인: "확인했어 아주 좋아")
  - 국면 전환 모핑(기본→공격→수비→기본 순환)을 GIF로. MediaRecorder는 SVG를 직접 스트리밍 못 해 결국 캔버스 래스터화가 필요하고 출력도 WebM이라 MP4 변환에 무거운 게 더 필요해서, 의존성 0개인 `gifenc`로 GIF89a를 직접 인코딩하는 쪽을 택함(조사 근거는 TO-DO-LIST.md 6번 상세 참조)
  - 핵심 설계는 실시간 녹화가 아니라 **가상 시간 스테핑** — Framer Motion 실제 재생을 녹화하는 대신 국면 사이 좌표를 미리 계산해(`lib/exportGif.ts`) 정지 이미지를 순서대로 캡처. 기존 PNG 캡처("모프 끝날 때까지 기다렸다 찍기")와 같은 결정론적 철학이라 캡처 타이밍이 기기 성능에 흔들리지 않음
  - `PrintPlayerNode`(정지 노드)·`AnimatedShareCard`(프레임 단위 카드)·`GifExportRunner`(프레임 순차 캡처+인코딩) 신규
  - 1차 확인 후 버그 2건 발견·수정: (1) GIF 카드가 PNG 카드(1080px) 치수를 축소 없이 그대로 써서 코멘트가 잘림 → `SCALE = GIF_CARD_SIZE/1080` 비율로 전체 치수 재계산, (2) 패스 공 애니메이션이 실시간(벽시계) 기준으로 도는데 가상 시간 캡처와 안 맞아 멈추거나 잔상이 남음 → `AnnotationLayer`에 `animated` prop 추가해 GIF에서는 공 자체를 안 그리고 화살표만 정적으로 표시
  - 커밋 `f5da460`(기능), `725ee99`(코멘트·패스 공 버그 수정)
