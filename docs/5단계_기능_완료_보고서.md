## 11. MVP 이후 추가 기능 — 감독 스타일 프리셋

MVP(Phase 1~6) 완료 후, 사용자 요청으로 `/new` 화면에 "감독 스타일 프리셋"을 추가했다. 원 기획(`1단계_요구사항_정의.md` §1.5)에는 없던 기능이라 별도 Phase 번호를 붙이지 않고 여기 기록한다.

- 배경: 사용자가 처음엔 "실제 경기를 검색해서 자동으로 불러오기"를 요청했으나, 조사 결과 무료/공개 축구 API는 출전 명단·포메이션 문자열까지만 제공하고 이 도구의 핵심인 "국면별 좌표"는 어떤 공개 API도 제공하지 않는다는 걸 확인했다(기업용 유료 트래킹 데이터 영역). 대신 실제 감독들의 잘 알려진 전술을 국면별로 재현한 프리셋으로 절충했다.
- 감독 6인, 프리셋 7개: 펩 과르디올라(맨시티), 미켈 아르테타(아스널), 위르겐 클롭(리버풀 시절 — **2025년부터 레드불 Head of Global Soccer로 현장을 떠남**, 레전드 스타일로 포함), 사비 알론소(레버쿠젠 무패 우승 시절 — **2026년 1월 레알 마드리드에서 경질, 현재는 첼시 감독**이지만 사용자 요청으로 레버쿠젠 시절 스타일 사용), 루이스 엔리케(PSG), 이정효(**광주FC 시절과 수원삼성 시절 둘 다** — 2026년 1월 광주에서 수원으로 이적).
- 각 감독의 전술적 특징(WebSearch로 2026-09-01 기준 실검증)을 반영해 국면별(기본/공격/수비) 좌표와 코멘트를 직접 설계했다 — 실제 선수 트래킹 데이터가 아니라 공개된 전술 분석 기사를 바탕으로 한 예시임을 각 파일의 `summary`/`comment`에 명시.
- 파일: `frontend/public/samples/managers/*.json` 7개. `frontend/src/lib/samples.test.ts`로 `public/samples/` 하위 모든 JSON(기존 샘플 포함 8개)이 `analysisSchema`를 통과하는지 자동 검증(Vitest).
- UI: `ManagerPresetPicker` + `lib/loadSample.ts`. `/new` 화면 상단에 감독 프리셋 7장, 하단에 기존 빈 포메이션 4장을 배치.
- 검증: Playwright로 3개 프리셋(과르디올라·사비 알론소·이정효 광주)을 실제로 불러와 매치명·선수 11명·국면 전환이 정상 동작하는지 확인, 콘솔 에러 0건.
